# Mkusic Android

基于 Sonora 的 Android 音乐播放器。默认使用手机独立模式，直接导入、解析、缓存和播放 B站音频；也可在设置中切换到服务器模式，连接同仓库 `server/` 的 Mkusic 服务。

当前版本 `0.3.0`，最低 Android 8.0。支持音乐库、搜索与分组、播放队列、进度拖动、随机/循环、后台媒体服务、通知控制和音频缓存。

## 手机独立模式

安装后即可使用，不需要部署服务器、配置域名、证书或访问密码。

1. 在手机音乐库右上角点 `+`，粘贴 BV/av/au 号、视频链接、B站短链接或公开收藏夹链接。
2. 添加成功后点歌曲播放；长视频可使用带 `?p=2` 等参数的完整链接选择分P。
3. 歌曲菜单可修改歌名、分组，或删除歌曲及它在手机上的音频缓存。
4. 播放会自动缓存已读取的音频，流式缓存上限 1 GB。要确保离线可用，选择歌曲菜单中的「完整缓存」，等待显示「已完整缓存」，再断网播放。
5. 完整缓存由 Android 前台下载服务处理，保存在 App 私有数据目录；设置中可以查看大小并清理，清理会停止播放，歌曲列表保留。卸载 App 会移除这些数据。

歌曲列表、分组、播放队列和进度保存在手机上，与服务器歌单分开。初次导入或获取未完整缓存的音频需要联网，流量由手机直接产生。独立模式暂不支持需要登录、会员或其他授权才能访问的音源；B站请求限制或接口变化仍可能影响未缓存歌曲。

需要原来的用法时，打开「设置 → 连接自己的音乐服务器」。切换模式会停止当前播放；已经保存的服务器连接信息和手机音乐库均保留。

## 构建

推荐使用 Android Studio 打开本目录，并按提示安装 Android SDK 34。也可配置 JDK 17+、Android SDK 后执行：

```bash
./gradlew testDebugUnitTest assembleDebug
```

Windows 使用 `gradlew.bat`。输出文件为 `app/build/outputs/apk/debug/app-debug.apk`。

使用服务器模式时，在连接页输入服务端地址，访问密码通过 Android Keystore 加密保存在设备上。服务器地址默认留空，HTTPS 使用系统信任证书；局域网私有 IP 支持 HTTP。

## 签名与安装更新

Debug 构建适合本地开发。不同电脑或 CI 生成的 Debug APK 可能使用不同签名，不保证互相覆盖安装。正式发布时应使用并长期保管自己的固定签名。

项目支持 `keystore.properties` 配置，参照 `keystore.properties.example`。签名文件与密码只留在本地或 CI Secrets 中，不提交源码。配置好签名后执行 `./gradlew assembleRelease`。

## 设备测试

`app/src/androidTest/` 中的集成测试需要运行中的测试音乐服务及设备/模拟器，并通过运行参数提供：

- `workstationServerUrl`：测试服务器地址。
- `workstationPassword`：测试服务密码。

播放、队列与重连测试需要至少两首可播放的 B站歌曲；封面测试需要带封面的歌曲。界面连接测试会修改测试手机的连接配置，请使用测试设备和测试服务。常规 CI 仅运行不访问个人服务器的单元测试与构建检查。
