# Mkusic

一个主要给自己听 B站音乐用的 Android 小播放器，边用边改，顺手放出来分享。安装 APK 后就能在手机上导入、解析、缓存和播放，不需要先部署服务器。

安卓端基于 [Sonora](https://github.com/SikamikanikoBG/Sonora) 修改，感谢原作者。项目还比较简单，如果刚好合用，欢迎拿去折腾。

当前版本 **0.3.4**，支持 **Android 8.0 及以上**。

[下载安装包](https://github.com/Myuknow/Mkusic/releases/latest) · [Android 使用与构建说明](android/README.md)

## 能做什么

- 导入 B站 BV / av / au 号、视频链接、短链接和公开收藏夹，读取歌名、作者与封面，支持选择视频分 P。
- 在手机上管理音乐库，搜索歌曲、修改歌名与分组，查看和调整播放队列。
- 边听边缓存，自动播放缓存上限 3 GB；支持单首完整缓存，也可一键缓存当前搜索、分组筛选后的列表，完整缓存后可离线播放。
- 支持顺序播放、列表循环、随机播放和单曲循环，以及后台播放、通知栏控制和进度拖动。
- 随机模式先生成一份可见的打乱队列，再按队列顺序播放；在播放队列里点「重新打乱」才重新排列，保留当前歌曲和进度。
- 音乐库、播放队列和进度保存在手机上，重启后可继续使用已保存的队列。

## 怎么用

1. 从 [Releases](https://github.com/Myuknow/Mkusic/releases/latest) 下载 APK 安装。
2. 打开 App，在手机音乐库右上角点 `+`，粘贴 BV 号或 B站链接，导入后点击歌曲播放。
3. 需要离线听时，在歌曲菜单选择「完整缓存」，或点击「一键缓存」。等待歌曲显示「已完整缓存」后再断网使用。
4. 点击底部小播放器进入正在播放页面，选择播放模式；随机模式下，打开播放队列可查看顺序并「重新打乱」。

播放时自动保存的部分缓存不等于完整离线下载。歌曲和缓存保存在 App 私有目录，卸载 App 会移除这些数据。

## 可选的服务器模式

仓库也保留了一个简单的网页音乐服务。需要用网页管理音乐，并让 App 连接同一个服务器音乐库时，可在「设置 → 连接自己的音乐服务器」中切换；手机独立音乐库与服务器音乐库分开保存。

服务端功能、启动方式、Docker、局域网连接、HTTPS 证书和备份说明，见 **[server/README.md](server/README.md)**。

## 当前限制

- 未完整缓存的歌曲需要联网，B站接口或 CDN 限制可能影响解析与播放。
- 手机独立模式暂不支持需要登录、会员或其他授权才能访问的音源。
- 不同手机的后台管理和媒体控制表现可能有差异。
